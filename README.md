## Overview

This repository contains the full computational infrastructure for the paper:

> Angrizanes Rossi, T.J., Mazzotti Silvestrini, M., Stanzani Klapka, C., Mori Sarti, F. (2026). *Modeling the Water–Energy–Food
> Nexus in Brazilian Periurban Watersheds: An Agent-Based Simulation Grounded in
> Institutional Governance Fragmentation and Climate Change Scenarios.*
> **Water (MDPI)**, Special Issue: "The Water–Energy–Food Nexus: Toward
> Integrated Solutions for Sustainability." DOI: *[to be inserted after acceptance]*

The agent-based model simulates Water–Energy–Food (WEF) nexus dynamics in the
Alto Tietê basin (UGRHI 6, São Paulo, Brazil — 36 municipalities). Heterogeneous
**farmers** are nested within **municipality** units that manage water; farmers
endogenously become rural solar prosumers when they adopt photovoltaic pumping.
Agent decisions are shaped by Brazil's institutionally fragmented WEF governance
(ANA / ANEEL / municipal zoning), producing emergent trade-offs across the nexus
under a historical baseline and IPCC AR6 climate scenarios (SSP2-4.5, SSP5-8.5).

## How to Reproduce

### Requirements

| Tool     | Version  | Purpose                          |
|----------|----------|----------------------------------|
| NetLogo  | 7.0.4    | ABM execution (`.nlogox` format) |
| R        | ≥ 4.3.0  | Preprocessing, analysis, figures |
| renv     | ≥ 1.0.0  | R environment reproducibility    |

### Steps

**1. Clone the repository**
```bash
git clone https://github.com/othiagorossi/wef-nexus-abm-br-watersheds-climate.git
cd wef-nexus-abm-br-watersheds-climate
```

**2. Restore the R environment**
```r
install.packages("renv")
renv::restore()
```

**3. Download and prepare input data**

Raw datasets are public (see `data/README_data.md` for URLs and access dates).
Run the preprocessing scripts in order — they produce the processed CSVs and the
model input file:
```r
source("analysis/00_download.R")       # download raw public datasets
source("analysis/01a_permits.R")       # ANA water permits
source("analysis/01b_land_cover.R")    # MapBiomas land cover
source("analysis/01c_solar.R")         # ANEEL distributed solar
source("analysis/01d_coverage.R")      # land-cover coverage shares
source("analysis/01e_model_inputs.R")  # build municipality_initial_conditions.csv
```

**4. Run the ABM**

Open `model/wef_nexus.nlogox` in **NetLogo 7.0.4** and run the scenario set with
**BehaviorSpace** (6 scenarios × 50 replicates), which writes the run table to
`outputs/tables/`. Then run the Morris sensitivity screening from R (executed via
`logolink`):
```r
source("analysis/03_morris_sensitivity.R")   # → outputs/tables/morris_mu_sigma.csv
```
See `model/ODD+D.md` for the full protocol.

> ⚠️ Edit `.nlogox` only through the NetLogo Code tab (save with Ctrl+S).
> Editing it in a plain-text editor corrupts the XML.

**5. Run the analysis and generate figures**
```r
source("analysis/02_scenario_analysis.R")     
source("analysis/05_map_ugrhi6.R")            
source("analysis/06_temporal_dynamics.R")     
source("analysis/08_morris_analysis.R")       
source("analysis/09_replicate_convergence.R") 
```
Each script sources `analysis/04_figures.R` for the shared palette, scenario
labels, and `save_fig()`. Output PDFs (300 DPI) are written to `outputs/figures/`.

## Scenarios

| ID | Climate    | Governance | Description                          |
|----|------------|------------|--------------------------------------|
| S0 | Historical | Fragmented | Baseline (validation)                |
| S1 | SSP2-4.5   | Fragmented | Moderate climate, status quo         |
| S2 | SSP5-8.5   | Fragmented | High emissions, status quo           |
| S3 | Historical | Integrated | Baseline climate, coordinated policy |
| S4 | SSP2-4.5   | Integrated | Moderate climate, coordinated policy |
| S5 | SSP5-8.5   | Integrated | High emissions, coordinated policy   |

Governance is contrasted as *fragmented* (emergency water restrictions triggered
above a stress threshold) versus *integrated* (demand-side water-use efficiency).
